# Agar online

## Jezik

Interfejs igre je na srpskom jeziku, latinicom.

## Objavljivanje na Renderu

1. Postavi fajlove projekta na GitHub.
2. Na Renderu izaberi **New +** → **Blueprint** i poveži taj GitHub repozitorijum.
3. Render će pročitati `render.yaml` i pokrenuti server.
4. Otvori Render adresu i podeli isti link sa svima. Nije potreban kod sobe; svi ulaze na jedan zajednički server.

Server prima do 20 istovremenih igrača, a tabela prikazuje sve povezane igrače. Besplatan hosting može da uspava servis kada nema aktivnosti, pa prvo povezivanje posle pauze može malo da potraje.
